# Cada archivo .txt de esta carpeta puede tener una o varias animaciones.
# Salen en Avatar > MOVIMIENTO (con un * al lado) y la elegida se hace en el
# juego con la tecla G. Tras cambiar un archivo, boton RECARGAR.
#
#   nombre   COMO SE LLAMA        (si coincide con una del juego, la sustituye)
#   duracion SEGUNDOS
#   bucle    si | no              (si = se repite hasta pulsar G otra vez o andar)
#   curva    natural | suave | lineal
#   T  canal=valor  canal=valor ...      una clave en el segundo T
#
# Los angulos van en grados. El lado: .i izquierda, .d derecha, .a los dos.
# Canales (rango sano entre parentesis; lo que se pase se recorta):
#   cuello.flex (-50..50)  cuello.giro (-70..70)  cuello.lado (-40..40)
#   torso.inclina (-14..63)  torso.giro (-30..30)  torso.lado (-35..35)
#   pelvis.inclina (-15..120)  pelvis.giro  pelvis.lado
#   hombro.X.encoger (0..1)  hombro.X.adelantar (-1..1)

#   codo.X (0..149)  antebrazo.X.prono (-80..86)
#   muneca.X.flex (-69..80)  muneca.X.desv (-20..32)
#   dedos.X.indice / medio / anular / menique / pulgar (0 abierto .. 1 cerrado)
#   dedos.X.abrir (-0.4..1)
#   pierna.X.flex (-20..120)  pierna.X.abd (-29..46)  pierna.X.rot (-35..45)
#   rodilla.X (0..137)  tobillo.X.flex (-50..20)  tobillo.X.lado (-15..30)
